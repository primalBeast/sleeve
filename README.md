# Sleeve

**App:** [https://primalBeast.github.io/sleeve/](https://primalBeast.github.io/sleeve/)

Loyalty cards live on your iPhone. An encrypted copy can sync to the private [`sleeve-vault`](https://github.com/primalBeast/sleeve-vault) repository.

## Try it

1. Open the link in **Safari** on your iPhone
2. Tap **Share → Add to Home Screen**
3. Photograph your cards
4. In **Settings**, add a fine-grained GitHub token with Contents access to `sleeve-vault` only, plus a backup passphrase

Do not make `sleeve-vault` public.
